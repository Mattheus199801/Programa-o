Fundos CSS

As propriedades de fundo do CSS são usadas para adicionar efeitos de fundo aos elementos.

Vamos aprender a utilizar a propriedade background no CSS.

  • background-color
  • background-repeat
  • background-image
  • background-attachment
  • background-position
  • background(abreviação de propriedade)

            A propriedade background-attachment especifica se a imagem de fundo deve rolar ou ser fixa (não rolará com o resto da página).
