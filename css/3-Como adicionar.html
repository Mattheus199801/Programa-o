Como adicionar CSS

Quando um navegador lê uma folha de estilo, ele formatará o documento HTML de acordo com as informações contidas nessa folha.

Existem três maneiras de inserir uma folha de estilo:

  1. CSS externo - link para um arquivo .css externo
  2. CSS interno - use o elemento <style> na seção <head>
  3. CSS embutido - utilize o atributo style em elementos HTML

Nesse exemplo, utilizaremos o modelo externo. (mais formal e recomendada)
