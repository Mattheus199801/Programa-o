Introdução ao Git

Etapas essenciais para começar

  • Crie uma pasta de projeto
  • Navegue até a pasta
  • Inicializar um repositório Git

        mkdir meuprojeto 
        cd meuprojeto

Inicializar Git

            git init 
            Initialized empty Git repository in /Users/user/myproject/.git/
            
            ls -a

Git Novos Arquivos

Um novo arquivo é um arquivo que você criou ou copiou para a pasta do seu projeto, mas para o qual você ainda não instruiu o Git a monitorá-lo.

            git status

O que é o ambiente de teste (staging environment)?

O ambiente de preparação (ou área de preparação ) é como uma sala de espera para as suas alterações.

Você o utiliza para informar ao Git exatamente quais arquivos deseja incluir no seu próximo commit.

Isso lhe dá controle sobre o que entra no histórico do seu projeto. 

            
    
                
  • git add index.html - Preparar um arquivo
    • 
                
  • git add --all ou - Implemente todas as alterações - git add -A
                
    • 
                
  • git status - Veja o que está sendo encenado
    •
