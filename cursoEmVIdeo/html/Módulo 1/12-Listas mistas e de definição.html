Lista de Definições

HTML
linguagem de marcação padrão usada para criar, estruturar e organizar o conteúdo de páginas na web.
CSS
Cascading Style Sheets (Folhas de Estilo em Cascata) e é a linguagem usada para estilizar e definir a aparência visual de páginas na internet.
JavaScript
linguagem de programação de alto nível usada para criar páginas web interativas
