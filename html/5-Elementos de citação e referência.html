Elementos de citação e referência em HTML

HTML <blockquote> para citações

Aqui está uma citação do site da WWF:

Há 60 anos, o WWF trabalha para ajudar as pessoas e a natureza a prosperarem. Como a principal organização de conservação do mundo, o WWF atua em quase 100 países. Em todos os níveis, colaboramos com pessoas ao redor do mundo para desenvolver e implementar soluções inovadoras que protegem as comunidades, a vida selvagem e os lugares onde vivem.

HTML <q> para citações curtas

Os navegadores geralmente inserem aspas em torno do elemento <q>

O objetivo do WWF é: Construir um futuro onde as pessoas vivam em harmonia com a natureza.

HTML <abbr> para abreviações

A OMS foi fundada em 1948.

A marcação de abreviações pode fornecer informações úteis para navegadores, sistemas de tradução e mecanismos de busca.

HTML <endereço> para informações de contato

O elemento de endereço HTML define as informações de contato (autor/proprietário) de um documento ou artigo.

    Escrito por John Doe.
    Visite-nos em:
    Example.com
    Caixa Postal 564, Disneyland
    EUA

HTML <cite> para Título da Obra

O elemento HTML cite define o título de uma obra.

Os navegadores geralmente exibem os elementos de citação em itálico.

O Grito,de Edvard Munch. Pintado em 1893.
