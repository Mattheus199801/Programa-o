Mesclagem de branches do Git

  •                 
                    git merge - Mesclar uma branch na sua branch atual
                
            
  •                 
                    git merge --no-ff - Sempre cria um commit de merge
                
            
  •                 
                    git merge --squash - Combina as alterações em um único commit
                
            
  •                 
                    git merge --abort - Aborta uma mesclagem em andamento
                
            
  •                 
                    Cancelar uma mesclagem: git merge --abort
                
            
  •                 
                    Verificar o status durante uma mesclagem: git status
                
            
  •                 
                    Resolva o conflito e conclua a mesclagem: Edite os arquivos em conflito e, em seguida ,git add filegit commit
                
            
  •                 
                    Mesclagem rápida (fast-forward merge): ocorre quando não há novas alterações no branch - o Git simplesmente move o ponteiro do branch para frente.
                
            
  •                 
                    Mesclagem sem avanço rápido: Use esta opção git merge --no-ff branchpara sempre criar um commit de mesclagem, preservando o histórico da branch.
