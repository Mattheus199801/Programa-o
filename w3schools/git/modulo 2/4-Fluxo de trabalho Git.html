Fluxo de trabalho Git

  • Diretório de trabalho - Onde você faz alterações
  • git add - Alterações de preparação
  • git commit - Salvar alterações no seu repositório
  • git push - Compartilhe as alterações com outras pessoas
  • git status - Verifique o que está acontecendo
  • Desfazer/Alterar - Corrigir erros 
     ( git restore, git reset, git commit --amend)

Desfazer e alterar alterações

  • git restore <file> - Desfazer alterações no diretório de trabalho (antes de preparar o ambiente).
  • git restore --staged <file> - Remover um arquivo da área de preparação (movê-lo para fora da área de preparação).
  • git reset HEAD~ - Desfazer a última alteração (mantém as alterações no diretório de trabalho).
  • git commit --amend - Altere a mensagem do último commit ou adicione arquivos ao seu último commit.
    • git restore --staged index.html
