Ajuda do Git

Atalhos de teclado para obter ajuda

Consulte a página do manual para obter um comando.

        
            git help <command>

Consulte a ajuda para obter mais informações sobre

        
            git <command> -- help

Veja um breve resumo das opções

        
            git <command -h

Listar todos os comandos Git possíveis

        
            git help --all

Listar guias e conceitos

        git help -g
