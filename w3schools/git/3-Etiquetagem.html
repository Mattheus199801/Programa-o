Etiquetagem Git

Atalhos de teclado para etiquetagem

  • - Crie uma etiqueta leve
    git tag v1.0<
  • - Criar uma etiqueta anotada
    git tag -a v1.0 -m "Teste 01"
  • - Marque um commit específico
    git tag v1.0 commit -hash
  • - Lista de etiquetas
    git tag
  • - Mostrar detalhes da etiqueta
    git show v1.0

Uma tag no Git é como um rótulo ou marcador para um commit específico.

Crie uma etiqueta leve

git tag v1.0

Criar uma Tag Anotada ( -a -m)

git tag -a v1.0 -m "Versão 1.0"

Marque um commit específico

git tag v1.0 1a2b3c4d

Mostrar detalhes da etiqueta ( git show)

git show

Enviar etiquetas para o controle remoto

git push origin v1.0

Enviar todas as tags

git push --tags

Excluir etiquetas

git tag -d v1.0

Atualizar ou substituir uma etiqueta (envio forçado)

git tag -f v1.0 1a2b3c4d
        git push --force origin v1.o
