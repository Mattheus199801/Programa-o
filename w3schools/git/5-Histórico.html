Histórico do Git

O Git mantém um registro detalhado de todas as alterações feitas em seu projeto.

Atalhos de teclado para visualizar o histórico

  • git logMostrar histórico completo de commits
  • git log --onelineExibir um resumo dos commits
  • git show <commit>Mostrar detalhes de um commit específico
  • git diffVer alterações não encenadas
  • git diff --stagedVeja as alterações faseadas
  • git log --author="Matheus Nunes"Mostrar commits por autor
  • git log --since="2 weeks ago"
  • git log --statMostrar arquivos alterados por commit
  • git log --graphExibir um gráfico de ramificação
