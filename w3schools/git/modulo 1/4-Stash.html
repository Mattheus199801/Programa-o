Às vezes, você precisa alternar rapidamente entre tarefas ou corrigir um bug, mas ainda não está pronto para concluir seu trabalho.

git stash
Permite salvar as alterações não confirmadas e retornar a um diretório de trabalho limpo.

Esconder com uma mensagem

git stash push -m "teste em projeto"

Listar todos os esconderijos

git stash list

Mostrar detalhes do estoque

git stash show

Aplicar o Stash mais recente 

git stash apply

Aplicar um estoque específico

git stash apply stash@{n}

Estoure o estoque

git stash pop

Deixe um estoque

git stash drop

Limpar todos os esconderijos

git stash clear

Ramo de um estoque 

git stash branch
