Configuração do Git

Configurar Git

Agora, informe ao Git quem você é.

Nome de usuário

            git config --global user.name "Nunes Alves"

Endereço de email

            git config --global user.email "exemplo@gmail.com"

Alterar ou remover valores de configuração

            git config --global --unset code.editot

Nome da filial padrão

Defina o nome padrão da ramificação para novos repositórios (por exemplo, mainem vez de master): 

        git config --global init.defaultBranch main

  • Sistema (todos os usuários):git config --system
  • Global (usuário atual):git config --global
  • Local (repositório atual):git config --local

A ordem de precedência é:

  • Local (repositório atual)
  • Global (usuário atual)
  • Sistema (todos os usuários)

Exemplo: Defina uma configuração local

        git config user.name "Project Name"
