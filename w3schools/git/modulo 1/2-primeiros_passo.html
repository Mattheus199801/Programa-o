Introdução ao Git

Etapas essenciais para começar

  • Crie uma pasta de projeto
  • Navegue até a pasta
  • Inicializar um repositório Git

        mkdir meuprojeto 
        cd meuprojeto

Inicializar Git

            git init 
            Initialized empty Git repository in /Users/user/myproject/.git/
            
            ls -a

Git Novos Arquivos

Um novo arquivo é um arquivo que você criou ou copiou para a pasta do seu projeto, mas para o qual você ainda não instruiu o Git a monitorá-lo.

            git status

O que é o ambiente de teste (staging environment)?

O ambiente de preparação (ou área de preparação ) é como uma sala de espera para as suas alterações.

Você o utiliza para informar ao Git exatamente quais arquivos deseja incluir no seu próximo commit.

Isso lhe dá controle sobre o que entra no histórico do seu projeto. 

            
    
                
  • git add index.html - Preparar um arquivo
    • 
                
  • git add --all ou - Implemente todas as alterações - git add -A
                
    • 
                
  • git status - Veja o que está sendo encenado
    • 
                
  • restore --staged index.html - Desfazer a preparação de um arquivo
    •

Commit do Git

Um commit é como um ponto de salvamento no seu projeto.

Ele registra um instantâneo dos seus arquivos em um determinado momento, com uma mensagem descrevendo o que mudou. 

        
    
            Aqui estão alguns comandos importantes para realizar commits:
            
  • git commit -m "message" - Confirme as alterações em etapas com uma mensagem
    • 
            
  • git commit -a -m "message" - Confirmar todas as alterações rastreadas (ignorar a preparação)
    • 
            
  • git log - Ver histórico de commits
    •

Outras opções úteis de commit

  • Crie um commit vazio: 
    git commit --allow-empty -m "Start project"
  • Adicione rapidamente as alterações preparadas ao último commit, mantendo a mensagem: 
    git commit --amend --no-edit
  • Usar a mensagem de commit anterior (sem editor): 
    git commit --no-edit

Solução de problemas e erros comuns de commit

  • Acidentalmente, adicionou os arquivos errados? 
    git reset --soft HEAD~1
  • Erro de digitação na sua mensagem de commit? 
    git commit --amend -m "Corrected message"
  • Ver histórico de commits 
    git log
