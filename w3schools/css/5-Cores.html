Cores CSS

Em CSS, as cores são especificadas usando um nome de cor predefinido ou um valor RGB, HEX, HSL, RGBA ou HSLA.

COLOR

Em CSS, uma cor pode ser especificada usando um nome de cor predefinido:

RGB / RGBA

Um valor de cor RGB representa fontes de luz VERMELHA, VERDE e AZUL.

HEX / HEXA

Uma cor hexadecimal é especificada com: #RRGGBB.

HSL / HSLA

HSL significa matiz, saturação e luminosidade.
