Seletores CSS

O seletor de Classe CSS

O class seletor seleciona elementos HTML com um atributo de classe específico.

Os seletores CSS são usados ​​para "encontrar" (ou selecionar) os elementos HTML que você deseja estilizar.

O seletor de ID CSS

O id seletor utiliza o atributo id de um elemento HTML para selecionar um elemento específico.
