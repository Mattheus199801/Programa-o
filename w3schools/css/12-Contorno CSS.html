Contorno CSS

Um contorno é uma linha desenhada ao redor de elementos, FORA das bordas, para fazer com que o elemento "se destaque".

Este elemento possui uma borda preta de 2px e um contorno verde com largura de 10px.

Deslocamento de contorno CSS

Essa outline-offset propriedade adiciona um espaço entre o contorno e a borda de um elemento. O espaço entre um elemento e seu contorno é transparente.
