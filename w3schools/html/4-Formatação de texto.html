Formatação de texto HTML

O HTML contém diversos elementos para definir texto com um significado específico.

Elementos de formatação HTML

Os elementos de formatação foram projetados para exibir tipos especiais de texto:

  • <strong> - Texto importante
  • <em> - Texto enfatizado
  • <mark> - Texto marcado
  • <small> - Texto menor
  • <del> - Texto excluído
  • <ins> - Texto inserido
  • <sub> - Texto em subscrito
  • <sup> - Texto sobrescrito
