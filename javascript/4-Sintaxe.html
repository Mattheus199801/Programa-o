Sintaxe JavaScript

Um identificador é o nome que você dá a uma variável.

    Regras para identificadores:

  • Deve começar com uma letra, _, ou $
  • Pode conter dígitos após o primeiro caractere.
  • Não pode ser uma palavra-chave reservada (let, const, if, etc.).
  • São sensíveis a maiúsculas e minúsculas
