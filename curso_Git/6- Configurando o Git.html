06. Configurando o Git - Git e Github para Iniciantes

Configura nome do usuário

        
            git config --global user.name "Sombra da Noite"

Configura e-mail do usuário

            
                git config --global user.email "Somobra1545@gmail.com"

Configura editor do usuário

            
                git config --global core.editor vscod

cirando nova pasta 

            
                mkdir git-course

acessa a pasta

            
                cd git-course/

Incicializar um repositorio

            
                git init

Consulta o Status do git

            
                git status

Adicionando o arquivo no git

            
                git add curso.git

comitar no git 

            
                git commit -m "Novo arquivo criado"

Comando log para vericar usuáriso

            
                git log
            
        
            
                git log --decorate
            
        
            
                git log --author="Sombra"
            
        
            
                git shortlog
            
        
            
                git shortlog -sn
            
        
            
                git log --graph
            
        
            
                git show 1d1dfsa15fdaf156f5s1fcw5s4er5wd1w5sf4w54rf
