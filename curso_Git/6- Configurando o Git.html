06. Configurando o Git - Git e Github para Iniciantes

Configura nome do usuário

        
            git config --global user.name "Sombra da Noite"

Configura e-mail do usuário

            
                git config --global user.email "Somobra1545@gmail.com"

Configura editor do usuário

            
                git config --global core.editor vscod
